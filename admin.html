      How to publish
      
    
        
  1. Open your GitHub repository for the site.
    2. 
        
  2. Open the posts folder → Add file → Upload files → drop the downloaded media file(s) → Commit changes.
    3. 
        
  3. Go back to the main folder → Add file → Upload files → drop the new posts.json (it replaces the old one) → Commit changes.
    4. 
        
  4. Wait about 30 seconds — Vercel updates the site and the post appears on the Feed.
    5. 
      

      
GitHub's website only accepts files under 25 MB. Keep videos short (under ~60 s, 720p) or ask Claude to compress them first.

      
To delete or edit a post: open posts.json on GitHub, click the pencil icon, change or remove that post's block, and commit.
